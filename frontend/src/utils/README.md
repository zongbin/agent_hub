# utils 目录

纯工具函数，无副作用、无 UI 依赖。

## 文件命名规范

| 文件        | 职责                              |
| ----------- | --------------------------------- |
| `format.ts` | 日期格式化、文件大小格式化          |
| `token.ts`  | JWT Token 的读取 / 写入 / 清除     |
| `sse.ts`    | SSE 流解析辅助（按 `data:` 行拆分） |

## 约定

- 工具函数必须为 `export` 的纯函数，不持有组件状态。
- 禁止在此目录引入 `element-plus` / `vue-router` 上下文。
