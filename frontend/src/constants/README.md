# constants 目录

全局枚举与常量，前后端共享概念在此集中定义。

## 文件命名规范

| 文件          | 职责                                |
| ------------- | ----------------------------------- |
| `api.ts`      | API 路径前缀、SSE 事件名常量          |
| `business.ts` | 角色枚举、安全等级枚举、文档类型枚举   |

## 约定

- 枚举值与后端 `application.yml` 及数据库 `CHECK` 约束保持一致。
- 不要在此目录放业务逻辑。
