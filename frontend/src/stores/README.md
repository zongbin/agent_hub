# stores 目录

Pinia 状态管理，按业务域拆分子文件。

## 文件命名规范

| 文件              | 职责                          |
| ----------------- | ----------------------------- |
| `user.ts`         | 当前登录用户信息、Token、权限   |
| `agentTask.ts`    | 当前 Agent 任务 / 步骤实时状态  |

## 约定

- 每个 store 文件对应一个 `defineStore`。
- 仅存放全局跨页面共享状态；页面局部状态用组件内 `ref` / `reactive`。
