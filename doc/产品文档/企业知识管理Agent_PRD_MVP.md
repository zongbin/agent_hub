# 企业知识管理 Agent — MVP 产品需求文档

> **产品名称**：智知 AgentHub
> **版本**：V2.0-MVP（含超级智能体）
> **日期**：2026-10-27
> **适用对象**：中小型企业（50-500人）

---

## 一、产品定位

**一句话**：让企业散落各处的文档，能在一个入口用自然语言秒问秒答；复杂任务交给超级智能体自主规划执行。

### 解决的核心痛点

| 痛点 | 解决方案 |
|------|---------|
| 资料分散，找文档要翻 5 个地方 | 统一上传 + 语义检索 |
| 新人问重复问题，老员工被问烦 | 智能问答，7×24 在线 |
| 写报告/方案要东拼西凑，费半天劲 | **超级智能体自主规划，5 分钟搞定** |
| 文档版本混乱，不知道哪个最新 | AI 检测过期 + 权限控制 |

## 三、MVP 功能清单

| 模块 | MVP 功能 | 优先级 |
|------|---------|--------|
| **知识库** | 拖拽上传 PDF/Word/PPT/Excel/Markdown，AI 解析生成摘要 | P0 |
| **智能问答** | 基于知识库的 RAG 问答，答案带原文引用 | P0 |
| **超级智能体** | 接收复杂目标 → 自主规划 → 调用工具执行 → 交付结果 | P0 |
| **权限控制** | 4 个角色 + 3 级密级 + 文档级权限 | P0 |

### MVP 不做（留到 V2）

- ❌ 知识图谱
- ❌ 高级权限（字段级脱敏、IP 白名单、水印）
- ❌ 多模型适配（先接一个）
- ❌ 数据源权限继承（手动配置）
- ❌ Agent 市场 / 自定义编排

## 四、超级智能体（核心亮点）

### 4.1 能力定义

**智知 SuperAgent** 是一个具备自主规划能力的 AI 智能体。用户用自然语言描述一个复杂目标，SuperAgent 自动完成：

1. **理解目标** — 解析用户意图，明确交付物
2. **拆解规划** — 将复杂任务拆成可执行的子步骤
3. **调用工具** — 每个步骤调用合适的工具（搜索、阅读、生成、计算等）
4. **执行交付** — 逐步执行，汇总结果，输出最终成果

### 4.2 工作流程

```
用户: "帮我分析一下竞品 X 的产品功能，输出对比报告"

SuperAgent 内部执行:

  [规划阶段] 拆解为 5 步:
  ① 搜索知识库中关于竞品 X 的文档
  ② 搜索知识库中我方产品资料
  ③ 提取双方功能清单
  ④ 生成对比分析表格
  ⑤ 输出完整报告

  [执行阶段]
  Step 1 → 调用「知识搜索」→ 找到 3 篇相关文档 ✅
  Step 2 → 调用「知识搜索」→ 找到 5 篇产品文档 ✅
  Step 3 → 调用「文档阅读」→ 提取功能点 32 个 ✅
  Step 4 → 调用「内容生成」→ 生成对比表格 ✅
  Step 5 → 调用「文档输出」→ 生成 Markdown 报告 ✅

  [交付] 报告已生成，共 2800 字，包含 5 个维度的对比
```

### 4.3 架构设计（Plan-and-Execute 模式）

```
┌──────────────────────────────────────────────────┐
│               智知 SuperAgent                     │
│                                                  │
│  ┌────────────┐    ┌────────────┐                │
│  │ 规划器      │───▶│ 执行器      │                │
│  │ (Planner)  │    │ (Executor) │                │
│  │            │    │            │                │
│  │ 接收目标   │    │ 按步骤调用  │                │
│  │ 拆解为步骤  │    │ 工具执行    │                │
│  │ 确定工具   │    │ 收集结果    │                │
│  └────────────┘    └─────┬──────┘                │
│        ▲                 │                       │
│        │                 ▼                       │
│  ┌─────┴──────────────────────┐                  │
│  │        工具层 (Tools)       │                  │
│  │                            │                  │
│  │  🔍 知识搜索 (RAG)         │                  │
│  │  📄 文档阅读 (按权限)       │                  │
│  │  ✍️ 内容生成 (报告/方案)    │                  │
│  │  📊 数据分析 (表格/图表)    │                  │
│  │  🔗 API 调用 (外部系统)     │                  │
│  └────────────────────────────┘                  │
└──────────────────────────────────────────────────┘
```

> **为什么用 Plan-and-Execute 而不是 ReAct？**
> - Plan-and-Execute 先生成完整计划再执行，用户可以**看到计划并修改**
> - 步骤清晰可追踪，出了问题能定位到具体步骤
> - 适合企业场景：可预期、可审计、可干预

### 4.4 工具清单（MVP）

| 工具 | 功能 | 说明 |
|------|------|------|
| **知识搜索** | 语义检索知识库中相关文档 | 受用户权限限制 |
| **文档阅读** | 读取指定文档全文或片段 | 受文档密级限制 |
| **内容生成** | 基于上下文生成报告/方案/总结等 | 引用溯源 |
| **数据分析** | 生成对比表格、统计计算 | 结构化输出 |
| **API 调用** | 调用外部系统（OA、CRM等） | 预留接口，MVP 可简化 |

### 4.5 用户交互（对话式）

用户在现有问答界面中直接输入复杂任务。SuperAgent 自动判断：

- **简单问题** → 直接走 RAG 问答（秒回）
- **复杂任务** → 触发 SuperAgent 模式（展示规划 + 逐步执行）

**对话中的 Agent 执行面板：**

```
┌─────────────────────────────────────────┐
│ 🤖 SuperAgent 正在执行                   │
│                                         │
│ 📋 任务计划                              │
│  ✅ 1. 搜索竞品 X 相关资料               │
│  ✅ 2. 搜索我方产品文档                   │
│  🔄 3. 提取功能对比点        ← 当前步骤   │
│  ⏳ 4. 生成对比表格                       │
│  ⏳ 5. 输出完整报告                       │
│                                         │
│ [暂停] [跳过当前步] [修改计划]           │
└─────────────────────────────────────────┘
```

### 4.6 MVP 目标场景（3 个）

| 场景 | 用户输入 | Agent 做什么 |
|------|---------|-------------|
| **竞品分析** | "分析竞品 X 和我们的优劣" | 搜索双方资料 → 提取功能点 → 生成对比表 → 输出报告 |
| **项目方案** | "帮我写一个 XX 项目的启动方案" | 搜索类似项目 → 提取模板 → 生成方案 → 输出文档 |
| **会议纪要整理** | "整理本周 3 次会议纪要的行动项" | 读取纪要 → 提取行动项 → 去重合并 → 生成跟踪表 |

### 4.7 权限约束

SuperAgent 执行中同样遵守权限规则：
- 知识搜索只返回用户有权限的文档
- 文档阅读受密级限制
- 无权限的步骤标记为「🔒 权限不足，已跳过」
- 最终报告不包含无权限内容

## 五、权限控制设计

### 5.1 4 个角色

| 角色 | 谁能当 | 能做什么 |
|------|--------|---------|
| **管理员** | IT/知识负责人（1-2人） | 全部权限 + 系统配置 |
| **编辑者** | 各部门骨干（5-10人） | 上传/编辑文档、使用 SuperAgent |
| **查看者** | 全体员工 | 查看授权文档、基础问答 |
| **访客** | 外包/临时人员 | 仅看授权文档 |

> **注意**：SuperAgent 仅对「管理员」和「编辑者」开放，因为涉及多文档调度和内容生成。

### 5.2 3 级密级

| 密级 | 标识 | 谁能看 |
|------|------|--------|
| **公开** | 🟢 | 所有人（含访客） |
| **内部** | 🔵 | 仅正式员工 |
| **机密** | 🔴 | 仅授权人员 |

### 5.3 权限校验流程

```
用户请求
  → 登录了吗？(SSO)
  → 是什么角色？
  → 文档是什么密级？
  → 在允许范围内吗？
  → 返回数据 / 拒绝
```

## 七、技术架构

```
┌──────────┐     ┌──────────────────────────────────┐
│ Web 前端  │────▶│           API 服务 (Spring)       │
│ (Vue 3)  │     │                                  │
└──────────┘     │  ┌─────────┐  ┌──────────────┐   │
                 │  │ Q&A 服务 │  │ SuperAgent   │   │
                 │  │ (RAG)   │  │ 服务          │   │
                 │  └────┬────┘  └──────┬───────┘   │
                 │       │              │           │
                 │  ┌────┴──────────────┴──────┐    │
                 │  │       工具层 (Tools)      │    │
                 │  │  搜索/阅读/生成/API       │    │
                 │  └──────────────────────────┘    │
                 └──────────────┬───────────────────┘
                                │
                 ┌──────────────┼──────────────┐
                 │              │              │
          ┌──────┴──────┐ ┌─────┴─────┐ ┌──────┴──────┐
          │  PostgreSQL  │ │  Milvus   │ │  LangGraph  │ │   LLM       │
          │  (元数据+权限)│ │ (向量库)  │ │  (Agent编排) │ │ (DeepSeek)  │
          └─────────────┘ └───────────┘ └─────────────┘ └─────────────┘
```

**SuperAgent 技术要点**：
- **架构模式**：Plan-and-Execute（业界验证最适合企业多步工作流的模式）
- **编排框架**：LangGraph（成熟的 Plan-and-Execute 支持 + 状态持久化）
- **模型路由**：规划阶段用强模型（Sonnet/DeepSeek），执行步骤用小模型（Haiku/Qwen-mini）—— 省成本
- 规划器：LLM 生成结构化 JSON Plan
- 执行器：按 Plan 步骤顺序调用 Tool
- 每个 Tool 是标准函数，输入输出结构化
- 执行状态持久化（SQLite/Postgres），支持断点续执
- 流式输出（SSE），前端实时展示执行进度
- **HITL（人在回路）**：写操作（发邮件、改数据）需人工确认，读操作自动执行

## 八、部署方案

### 最小配置（50-200人）

- 1 台服务器：8C16G，500G SSD
- Docker Compose 一键部署
- 每日自动备份

### 推荐配置（200-500人）

- 2 台服务器：应用 + 向量库分离
- 负载均衡 + 异地备份
