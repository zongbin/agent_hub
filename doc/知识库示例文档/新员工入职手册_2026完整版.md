版本号：V4.2 | 生效日期：2026年1月1日 | 归属部门：人力资源部
适用范围：全体新入职正式员工、试用期员工
文档密级：内部公开

## 第一章 入职报到流程

### 1.1 报到时间与地点
新员工应在收到《录用通知书》后，按照约定日期准时报到。报到时间为工作日上午 9:00 - 10:00，地点为公司总部 A栋1楼 前台接待处。如因特殊原因无法按时报到，须提前2个工作日联系HRBP（人力资源业务伙伴）申请延期，延期最长不超过5个工作日。

### 1.2 报到所需材料
新员工报到当日需携带以下材料原件及复印件各一份：
1. 本人身份证原件及复印件（正反面复印在同一张A4纸上）
2. 最高学历学位证书原件及复印件
3. 前单位离职证明原件（应届生提供三方协议或就业推荐表）
4. 近三个月内二级甲等及以上医院体检报告（含胸透、血常规、肝功能）
5. 一寸白底免冠照片2张
6. 本人银行卡复印件（工资卡，支持工商银行、招商银行、建设银行）
7. 个人社保/公积金转移单（如有）

### 1.3 入职当天流程
入职当天的标准流程如下：
- 09:00 - 09:30：前台签到，领取《新员工报到单》，提交材料
- 09:30 - 10:30：HR办理入职手续，签署劳动合同、保密协议、竞业限制协议
- 10:30 - 11:30：IT部门发放办公设备，开通企业邮箱、飞书账号、OA权限
- 11:30 - 12:00：部门助理带领熟悉办公环境，介绍团队成员
- 13:30 - 15:00：参加新员工入职培训（企业文化、制度宣导）
- 15:00 - 17:00：部门内部业务培训（由直属主管安排）

## 第二章 试用期管理

### 2.1 试用期时长
根据劳动合同期限确定试用期：
- 合同期限1年（含）至3年（不含）：试用期2个月
- 合同期限3年（含）以上或无固定期限：试用期6个月
- 以完成一定工作任务为期限的合同：不约定试用期

### 2.2 试用期考核
试用期考核分为月度跟踪和期末评估两个环节：
1. **月度跟踪**：每月末由直属主管填写《试用期月度反馈表》，从工作能力、学习态度、团队协作、文化融入四个维度进行评价，评分采用5分制。
2. **期末评估**：试用期最后一周，由直属主管、隔级主管、HRBP三方组成评审小组，进行转正答辩。答辩时间控制在30分钟以内，包含15分钟个人述职和15分钟评委提问。

### 2.3 转正标准
转正需同时满足以下条件：
- 月度跟踪平均分不低于 3.5 分（满分5分）
- 期末答辩评审小组一致同意通过
- 试用期内无严重违纪记录
- 完成所有必修培训课程并通过考核

未通过转正评估的员工，公司有权延长试用期一次（最长不超过法定上限）或依法解除劳动合同。

### 2.4 试用期离职
试用期内员工提出离职，需提前3天书面通知。公司提出解除的，需说明理由并依法支付经济补偿。试用期内工资不低于转正后工资的80%，且不低于当地最低工资标准。

## 第三章 薪酬与福利

### 3.1 薪酬结构
公司薪酬由以下部分组成：
- **基本工资**：根据岗位职级确定，每年4月进行一次年度调薪评审
- **绩效奖金**：按季度发放，与个人绩效评级（S/A/B/C/D）和部门业绩挂钩
- **专项补贴**：包含餐补（30元/天）、交通补贴（500元/月）、通讯补贴（200元/月）
- **年终奖**：根据公司年度经营状况和个人年度绩效综合确定，一般为1-4个月工资

### 3.2 发薪日与社保
- 发薪日为每月 **10日**（遇节假日提前至最近工作日）
- 社保公积金按入职当月实际出勤天数计算，次月起正常缴纳
- 公积金缴纳比例：公司12% + 个人12%
- 社保缴纳基数：按上年度月平均工资确定，每年7月调整

### 3.3 补充福利
- **商业保险**：入职满3个月后，公司统一购买补充医疗保险（含门诊、住院、意外）
- **年度体检**：每年9月安排一次免费体检，入职不满半年的员工可参加次年体检
- **学习基金**：每人每年享有 5000元 学习发展基金，可用于购买课程、书籍、参加考试认证
- **弹性福利**：入职满1年后，可在弹性福利平台自选健身卡、子女教育补贴、旅游基金等，额度为 3000元/年

## 第四章 办公行为规范

### 4.1 着装要求
公司实行商务休闲（Business Casual）着装标准：
- 工作日：整洁得体即可，不强制正装。禁止穿拖鞋、背心、短裤进入办公区
- 客户拜访/正式会议：需着正装或商务装
- 每周五为"自由着装日"，可穿休闲服饰

### 4.2 办公环境
- 工位保持整洁，下班后关闭电脑显示器及非必要电源
- 会议室使用需在飞书日历中提前预约，单次预约不超过2小时
- 公共区域（茶水间、休息区）使用后自行清理，保持整洁
- 办公区内禁止大声喧哗、外放音乐，接听私人电话请移步至电话亭

### 4.3 信息安全
- 严禁将公司内部文件、代码、数据通过个人邮箱、网盘、U盘等渠道外传
- 离开工位超过5分钟须锁屏（Windows: Win+L / Mac: Ctrl+Cmd+Q）
- 不得在公共场所（咖啡厅、高铁、飞机）讨论公司未公开的商业信息
- 发现信息安全事件（如钓鱼邮件、数据泄露），立即报告IT安全部（分机：8099）

## 第五章 培训与发展

### 5.1 新员工培训体系
新员工入职后需完成以下必修培训：

| 培训项目 | 时长 | 完成时限 | 考核方式 |
| :--- | :--- | :--- | :--- |
| 企业文化与价值观 | 2小时 | 入职第1天 | 无 |
| 公司制度与合规 | 1.5小时 | 入职第1周 | 在线测试（80分及格） |
| 信息安全意识 | 1小时 | 入职第1周 | 在线测试（90分及格） |
| 产品与业务概览 | 3小时 | 入职第2周 | 无 |
| 岗位技能培训 | 由部门定 | 入职第1个月 | 主管评估 |

### 5.2 晋升通道
公司设置双通道晋升体系：
- **管理通道（M序列）**：M1主管 → M2经理 → M3高级经理 → M4总监 → M5 VP → M6 SVP
- **专业通道（P序列）**：P1初级 → P2中级 → P3高级 → P4资深 → P5专家 → P6首席

晋升评审每年两次（4月和10月），需满足当前职级最低任职年限（一般为1.5-2年），且近两次绩效评级不低于B。

### 5.3 内部转岗
员工在当前岗位工作满1年后，可申请内部转岗。流程为：
1. 与现直属主管沟通并获得同意
2. 在内部招聘平台投递目标岗位
3. 通过目标部门的面试评估
4. HR审批并办理转岗手续
转岗后试用期为1个月，期间薪酬按新岗位标准执行。

## 第六章 离职管理

### 6.1 离职类型与通知期
- **主动辞职**：正式员工需提前30天书面通知；试用期员工提前3天
- **协商解除**：双方协商一致，按协议执行
- **公司辞退**：依据《劳动合同法》相关条款执行

### 6.2 离职交接清单
离职员工须在最后工作日前完成以下交接：
1. 工作交接：与接替人完成项目文档、客户资料、进行中的任务交接，由直属主管签字确认
2. 资产归还：电脑、显示器、门禁卡、工牌等归还至IT服务中心
3. 账号注销：企业邮箱、飞书、OA、代码仓库等账号由IT统一关闭
4. 财务结算：确认无未结清的借款、报销款项
5. 竞业确认：如签署过竞业限制协议，HR将告知竞业期限及补偿标准

### 6.3 离职证明
离职手续全部完成后，HR将在 **5个工作日内** 出具《离职证明》。如需加急，可提前与HRBP沟通。
