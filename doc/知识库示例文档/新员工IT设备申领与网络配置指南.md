# 新员工 IT 设备申领与网络配置指南
最后更新：2026年2月15日 | 维护人：IT支持部-李四 (分机: 8012)

## 一、 办公设备申领
1. **电脑申领**：入职首日，由部门助理在飞书发起「IT资产领用」审批。研发岗默认配发 MacBook Pro 14寸 (M3芯片) 或 ThinkPad T14s；非研发岗默认配发 MacBook Air 或 联想 ThinkBook。如需特殊配置（如32G以上内存），需在审批中注明并由总监加签。
2. **显示器及配件**：每人标配一台 27寸 4K 显示器。如需双屏，请在内网 IT 服务台提交工单。
3. **领用地点**：A栋3楼 IT 服务中心（工作时间：9:30 - 18:00）。

## 二、 账号与权限激活
1. **企业邮箱**：入职当天系统自动生成，格式为 `姓名拼音@corp.com`。初始密码将通过短信发送至您入职登记的手机号，首次登录强制要求修改。
2. **飞书/企微**：使用企业邮箱作为账号登录，并绑定个人手机号进行二次验证（2FA）。
3. **内网 OA 系统**：访问 `oa.corp.com`，使用飞书扫码登录。

## 三、 办公网络连接
公司办公区提供两个主要 Wi-Fi SSID：
- **Corp-Staff**：供员工日常办公使用。采用 802.1x 认证，连接时输入您的企业邮箱账号和密码即可，切勿使用访客网络处理内部业务。
- **Corp-Guest**：仅供外部访客使用，需由接待人在飞书「访客系统」提前登记并生成临时密码。该网络无法访问公司内部代码库和 ERP 系统。

## 四、 常见故障自助排查
- **连不上 Corp-Staff**：请检查是否修改了域密码但未同步更新 Wi-Fi 密码。可在 Mac 的“钥匙串访问”中删除旧的 Wi-Fi 记录后重新连接。
- **打印机无法使用**：所有楼层打印机均支持漫游打印。请在飞书搜索“云打印”小程序，上传文件后获取取件码，前往任意打印机扫码输出。
